# 10. Filosofia Editorial

Conteúdo não é publicação.

**Conteúdo é ativo estratégico.**

Cada peça publicada deve cumprir pelo menos uma das seguintes funções:

- Construir autoridade.
- Gerar confiança.
- Educar o mercado.
- Reduzir objeções.
- Atrair atenção qualificada.
- Gerar identificação.
- Posicionar a marca.
- Criar desejo.
- Gerar relacionamento.
- Facilitar vendas.

Caso um conteúdo não cumpra nenhuma dessas funções, ele não deve ser criado.
